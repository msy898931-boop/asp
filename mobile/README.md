# ASTRA mobile app

A phone app for the ASTRA backend. It is a **PWA** (installable web app): no
store account, no build step, no APK. You open one URL once and add it to the
home screen; after that it opens full-screen like any other app.

## What it shows

- **Status** — a gauge for system health, plus mode, startup stage, symbol and
  the market-data source (clearly labelled when it is the synthetic replay feed).
- **Signal** — direction, regime, entry / stop / target / R:R, score and context.
- **Chart** — closed-bar candles for the nine canonical timeframes.
- **Bridge** — the loopback market-data link's own state.

Everything is read-only and shadow-mode: the app never places trades, and the
footer states this. The bridge stays bound to `127.0.0.1`; the launcher only
proxies `GET` requests to it.

## Run the server

The backend must already be running (it publishes the loopback API on 8790 and
the bridge on 8791). Then:

```bash
python3 mobile/serve_mobile.py --host 0.0.0.0 --port 12001 \
    --api-port 8790 --bridge-port 8791
```

Point the phone's browser at `http://<server-ip>:12001/`.

## Install on the phone (e.g. Moto G7, Android 9)

1. Connect the phone to the same network as the server (or use the server's
   public URL).
2. Open the app URL in **Chrome**.
3. Tap the **⋮** menu → **Add to Home screen** → **Install**.
4. Launch it from the home screen. It opens standalone, with its own icon.

If the URL is plain `http://` on the LAN, Chrome still installs it (the service
worker needs a secure context, so on `http://` the app runs but does not cache
offline; over `https://` it also works offline).

## Notes

- Icons are generated by `icons/make_icons.py` (standard library only) and are
  committed, so no image tooling is required to run the app.
- The fonts (Fraunces, IBM Plex Mono) load from Google Fonts when online and
  fall back to system serif/monospace offline.
